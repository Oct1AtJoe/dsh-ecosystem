# DeepSeek Harness Web 玻璃质感改造文档

> 改造日期：2026-08-28
> 改造目标：让 Web GUI 的设置弹窗、右侧折叠面板、下拉菜单获得统一的玻璃质感，并确保弹窗不被对话区域内容遮挡。
> 核心原则：**所有改动都在本地主题插件包中（`C:\dsh-ecosystem`），官方仓库源码保持原样。**

---

## 一、背景与问题

原始问题链：

1. **设置弹窗被对话 trace 遮挡**——弹窗 z-index 只有 1000，低于消息导航 rail（1001），且 DOM 在侧边栏内部，被对话区域内容盖住。
2. **设置弹窗样式异常**——冥夜主题的 `[role="dialog"]` 规则用 `rgba(46,46,56,0.97) !important` 强制实色，与玻璃质感冲突。
3. **色相不跟随主题**——弹窗背景硬编码，切换主题时不变。
4. **下拉面板透明度过高**——`--dsw-specific-menu` 默认指向 `bg-layer-3`（78% 透明），@ 候选面板内容不清晰。
5. **右侧折叠面板底色不统一**——主题 `_pane` 规则强制用 `--dsw-specific-sidebar-fill`，与其他区域色差明显。

### 关键发现：服务器读取路径

DSH web 服务器读取插件 bundle 的路径是 **profile 的 `node_modules`**，**不是** workspace 的构建产物：

```
C:\Users\Administrator\.dsh\profiles\web\node_modules\@deepseek-ai\dsh-client-ui-theme-custom\lib\client.js
```

因此每次改源码后，必须：**构建 → 复制 `lib/client.js` 到 profile 对应目录**，刷新页面才生效。

## 三、具体改动清单

### 1. 设置弹窗结构：z-index + isolation（移入主题包）

**文件**：`C:\dsh-ecosystem\plugins\ui-theme-custom\src\client\index.ts` → `SURFACE_GLASS_CSS`

```css
/* Settings/dialog full-viewport layer (the .overlay box, marked
   role="presentation", whose child is the role="dialog" panel): force a
   standalone stacking context at the top of the page so the dialog never
   competes with the message-nav rail (z 1001), sticky composer, or the
   conversation trace — a structural fix that lives with the theme, not the
   host package. */
[role="presentation"]:has(> [role="dialog"]){
  z-index: 2147483647 !important;
  isolation: isolate !important;
}
```

- **选择器**：`[role="presentation"]:has(> [role="dialog"])` 精确定位设置弹窗的 `.overlay` 容器（官方源码中 `<div class="overlay" role="presentation">`，内含 `role="dialog"` 子元素）。
- **作用**：把弹窗层提到页面最高 + 强制独立层叠上下文，彻底避免被 rail/composer/trace 覆盖。
- **背景**：官方 `.overlay` 的 `z-index: 1000` 被此规则以 `!important` 覆盖。

> 注：之前曾用 `createPortal(document.body)` 解决 DOM 位置问题，但 portal 是 JS 行为，属于官方源码。改为主题规则（z-index + isolation）后**不再需要 portal**，官方源码可以保持原样。

### 2. 设置弹窗视觉：玻璃质感（跟随主题色相）

**文件**：同上 `index.ts` → `SURFACE_GLASS_CSS`

```css
[role="dialog"]{
  background:
    linear-gradient(135deg, rgba(255,255,255,0.05) 0%, transparent 30%),
    linear-gradient(0deg, rgba(10,11,16,0.25) 0%, transparent 45%),
    color-mix(in srgb, var(--dsw-alias-bg-layer-2) 85%, transparent) !important;
  backdrop-filter: blur(32px) saturate(1.05) !important;
  box-shadow:
    0 0 0 1px rgba(200,198,204,0.22),
    inset 0 1px 0 rgba(255,255,255,0.12),
    0 6px 16px rgba(0,0,0,0.40),
    0 24px 60px rgba(0,0,0,0.50) !important;
}
```

- **色相跟随主题**：`color-mix(in srgb, var(--dsw-alias-bg-layer-2) 85%, transparent)` —— 底色 100% 来自主题的 `--dsw-alias-bg-layer-2`（冥夜 `rgb(30,30,34)`、极光 `rgb(42,34,60)`、星云 `rgb(34,38,68)` 等），切主题自动跟随。
- **不透明度 85%**：固定，不依赖主题 token 透明度（保证可读性）。
- **毛玻璃**：`blur(32px) saturate(1.05)`。
- **边缘**：亮描边 `rgba(200,198,204,0.22)` + 顶部内高光 + 双层投影（面板浮起感）。
- **辅助文字提亮**（同规则内）：
  ```css
  --dsw-alias-label-tertiary: rgb(178, 176, 188);
  --dsw-alias-label-caption: rgb(160, 158, 170);
  ```

### 3. 右侧折叠面板：底色统一 + 光斑中下

**文件**：同上 `index.ts` → `SURFACE_GLASS_CSS`

```css
[class$="_pane"]{
  background-color: var(--dsw-alias-bg-base) !important;
  position: relative; z-index: 0;
}
[class$="_pane"]::after{
  content: ''; position: absolute; inset: 0; pointer-events: none; z-index: -1;
  background:
    radial-gradient(440px 320px at 78% 68%, rgba(228,222,238,0.16), transparent 56%);
  box-shadow: inset 0 1px 0 rgba(255,255,255,0.05), inset 0 0 0 1px rgba(255,255,255,0.03);
}
```

- **底色**：`--dsw-alias-bg-base`（与中间对话区/页面底色统一），替代原来 `--dsw-specific-sidebar-fill`。
- **光斑**：从 `at 82% 12%`（右上角，被用户反馈"抛到上边"）移到 **`at 78% 68%`**（中下位置）。
- **强度**：`0.18 → 0.16`（更柔和）。

> 注意：`bg-app-image`（中间对话区的背景图，含右上 `at 88% 18%` 和左侧 `at 3% 42%` 两个光斑）**不要改动**——那是中间对话区的，保持原始位置。

### 4. 下拉菜单不透明度（`--dsw-specific-menu`）

**文件**：`C:\dsh-ecosystem\plugins\ui-theme-custom\src\client\void.ts` → `VOID_TOKENS`

```ts
'--dsw-specific-menu': 'rgba(30, 30, 37, 0.94)',
```

- **作用**：@ 展开候选面板、Menu 弹框等使用 `--dsw-specific-menu` 的菜单，从默认 78% 提升到 **94%** 不透明，内容更清晰。
- **只影响菜单**，不影响 `bg-layer-3` 的其他组件（Agent 卡片、插件卡片等）。
- 该 token 当前在源码中被还原过（记录在案），如需恢复需重新添加并部署。

## 六、常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 改了源码但页面没变 | 未部署到 profile（服务器读 profile 非 workspace） | 执行部署步骤 3 |
| 弹窗太透/看不清 | `color-mix` 的 85% 被覆盖或缺失 | 确认 dialog 规则含 `color-mix(...85%)` |
| 右侧光斑跑回左上 | `_pane` 规则被还原 | 确认 `at 78% 68%` 存在 |
| 菜单太透 | `--dsw-specific-menu` token 缺失 | 在 `void.ts` 重新添加 `rgba(30,30,37,0.94)` |
| 弹窗被 rail 覆盖 | `[role="presentation"]:has()` 规则缺失 | 确认该规则 + `z-index:2147483647` |
| 插件更新后改动丢失 | profile 文件被重装覆盖 | 用补丁脚本或 fork 重新应用 |
