# DSH 文件上传增强插件（File Upload Custom）v2.2.0

把 DSH Web GUI 原版**只支持图片**的附件通道，扩展为**任意文件上传与剪贴板增强**：拖入或 **Ctrl+V 粘贴**任意文件（PDF、3MF、ZIP、Excel、代码、图片……）→ 文件上传/引用到本机中转目录 → 输入框出现一个**蓝色文件 chip** → agent 可以直接读取该文件。

> **定位说明**：本插件的本质是**文件上传与引用功能**，不是"路径展示"。路径只是内部机制——agent 读取文件必须依赖磁盘路径，浏览器又拿不到，所以插件负责把文件物化到本机、并把路径交给 agent。用户界面不再出现任何路径概念：chip 只显示文件名，用户只需知道"文件就绪了，agent 能读了"。

本仓库是**本地生态定制插件**（`dsh.bundle` + `dsh.client` 双声明），遵循 `C:\dsh-ecosystem` 本地生态开发规范。

## 定制增强特性（v2.2.0）

- 📋 **全新支持 Ctrl+V 粘贴文件**：在 Windows 资源管理器直接按 `Ctrl+C` 复制文档（PDF/Word/Excel/ZIP 等），在 DSH 窗口按 `Ctrl+V` 秒级生成蓝色文件 chip。通过本地 Host 路由直接读取 Windows 系统的 `FileDropList`，彻底突破 WebView2 / Chromium 浏览器的沙盒限制。
- 🎯 **多会话精准定向，彻底杜绝会话漂移**：
  - 修复原版在工作区新建会话或打开多个会话时，文件被旧会话抢跑消费、漂移到第一个会话的 bug。
  - 将 Inserter 从非全覆盖槽位迁移至全生命周期常驻槽位 `conversation.input.overlay`，完美兼容新建空白对话（`hero` 模式）与历史对话。
  - 拖入/粘贴时即时锁定当前视口激活的会话 ID，非目标会话严禁消费。
- ✂️ **切除尾随空格，退格键一键整删**：
  - 解决 DSH 原生插入 Reference Chip 后强制补空格导致 Backspace 需要按两次才能删除的问题。
  - 在 Detect 坐标系下精准计算尾部位置，插入瞬间通过 `consumeToken` 切除多余空格，光标紧贴药丸，**按一次 Backspace 直接整删**。
- ✍️ **严密的剪贴板四路智能分流**：
  1. **纯文字**：直接放行原生 Lexical 编辑器，绝不拦截，普通打字/复制粘贴文本丝滑无感；
  2. **纯图片/截图**：放行 DSH 原生缩略图流程；
  3. **绝对路径文本**：自动识别为文件并插入 chip；
  4. **资源管理器复制文档**：桥接 Host 读取并生成文件 chip。
- 🧹 **界面极致清爽**：侧边栏垃圾桶槽位默认注释隐藏，不破坏原有界面布局。

## 继承特性

- 🖱️ **页面任意位置拖入任意文件**（多文件、图片均可）；拖拽时全屏提示"松开以接收文件"
- 📦 **任意文件类型**：原版"仅图片"附件通道被完全静默接管，任何文件都可拖入
- 📍 **本机文件零上传直引**：Chromium（Edge/Chrome/Tauri）拖拽会经 entry API 暴露源文件路径——直接引用，**零上传、零复制**；仅当浏览器拿不到路径时才走上传中转
- 🔵 文件以**一个整体 chip** 插入输入框：蓝色文字（**只显示文件名+格式**）、不可被局部删改
- 📐 **篮筐宽度随文件名自适应**：插入时用 composer 真实字体实测文件名宽度，pill 精确贴合（误差 <1 个字符）
- 🙈 **内部细节全部隐藏**：`.b64` 后缀、`_1/_2` 重名序号、中转目录路径——用户界面永远看不到；提交给 agent 的才是完整真实路径
- ♻️ **两级去重（先查后传，防误复用）**：`begin` 快路径命中条件 = 同名 + 同大小 + manifest 登记的源修改时间一致——重复拖同一文件秒回（零上传）；编辑过但字节数未变的文件完整上传后由 sha256 裁决
- 🛡️ **完整性校验**：分块精确长度校验、解码后字节数校验——截断/缺块/伪造数据一律拒绝

## 工作原理

| 部件 | 位置 | 职责 |
|---|---|---|
| Host 半（`lib/index.js`） | 宿主进程，`inject: ['webServer']` | HTTP 路由 `/api/file-upload/*`：分块校验、两级去重、PowerShell Windows 剪贴板读取（`/api/file-upload/clipboard`）、node:fs 落盘 |
| Client 半（`lib/client.js`） | 浏览器（`__ModuleLoader__` bundle，`dsh.client` 声明） | 全局拖拽与 Ctrl+V 粘贴监听、智能分流、插入点待机圆环、注册 trigger source、活跃会话锁定、经 `input.insertReference` 插入文件 chip |

## 版本历史

- **v2.2.0（当前定制增强版）**：
  - **新增 Ctrl+V 粘贴文档支持**：新增 Host 端 `/api/file-upload/clipboard` 路由读取 Windows 剪贴板文件列表；Client 端四路智能分流。
  - **修复多会话漂移缺陷**：`DockInserter` 迁移至 `conversation.input.overlay`，锁定活跃会话 ID。
  - **修复尾随空格问题**：精确 Detect 坐标定位，插入后即时消费尾随空格，实现单次退格整体删除。
  - **隐藏侧边栏垃圾桶**：默认注释槽位注册，减少视觉干扰。
- **v2.1.0**：修复快路径误复用、清单误标、失败泄漏、插入乱序等问题。
- **v2.0.0**：正式更名 `dsh-file-upload`，移除路径展示，全面转向文件上传体验。
